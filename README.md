# MixSwell updates

SwellAudio's public release channel for **MixSwell**, the vocal chain plugin.

- **Download MixSwell:** https://mixswell-license.tanjuhoja631.workers.dev/download
- Installers are attached to this repository's [releases](../../releases): a macOS package
  (Apple Silicon and Intel; VST3 and AU) and, later, a Windows installer (VST3).
- `latest.json` and `latest.json.sig` (from the first release on) tell MixSwell that a new version is
  out. MixSwell checks the signature with SwellAudio's own update key and the size and SHA-256 of
  every installer it downloads, so a changed manifest or file is ignored.

Nothing else lives here: MixSwell's source code and its license service are private.
